## 二、纯代码渲染核心工程铁律（实测总结）

> **为什么纯代码能做到电影级高级感？核心秘诀在于「人物高度造型化，环境光影拉满」：**
> - 实测证明：用纯 SVG 硬画 5.5 头身写实动漫五官与复杂衣褶极易显得僵硬（PPT 矢量感）；
> - 只要人物采用 **方头 Q 版（A）/ 像素小人（B）/ 无描边纸偶（C）/ 水墨广袖剪影（D）/ 霓虹逆光剪影（E）/ 大头煮沸线涂鸦（F）/ 无黑描边白边贴纸 Q 版（G）**，再搭配 SVG 滤镜（`feDropShadow`、`feDisplacementMap`、`feTurbulence`、`feGaussianBlur`、`feMorphology`），纯代码渲染就能稳定达到惊艳的独立动画质感！

### 1. 风格 C（层叠纸雕）代码要点
- 使用 `Math.floor(frame / 2) * 2` 制造 15fps 轻微定格手作韵律；
- 5 层独立 `<g filter="url(#pcShadow...)">`：背景背光弯月 → 纸云 → 远山 → 6 层波浪纸带（每层顶部配亮色切边描线）→ 崖坡与剪纸恋人 → 前景剧场镂空画框；
- 顶层叠 `feTurbulence` 棉纸纹理（`mixBlendMode: 'overlay'`）。

### 2. 风格 D（国风写意水墨）代码要点
- 宣纸暖底（`#F3EEE2`）必须留出 **45%–55% 呼吸留白**；
- 远山路径套用 `feTurbulence` + `feDisplacementMap (scale=24)` + `feGaussianBlur (4.5)` 模拟湿墨渗入宣纸的毛边；
- 整帧克制使用墨黑/青灰，**唯一高饱和暖色留给朱砂红（`#C93B32`）油纸伞、梅花瓣、发簪与落款红印**，搭配右侧/左侧竖排古风楷体字幕。

### 3. 风格 E（90s City Pop 霓虹剪影）代码要点
- 背景采用品红-紫罗兰-暖橘渐变天空 + 水平闪烁海面波光 + 发光都市剪影 + 柔焦路灯圆锥光晕；
- 人物用深紫黑剪影（`#16132B`）叠加外轮廓渐变频闪/霓虹边缘光（`stroke="url(#rimPink)"` + `feGaussianBlur` Bloom），配合 2.35:1 上下电影黑边与 35mm 胶片噪点；
- 若用户需要精细写实动漫脸特写，再明确建议改用「AI 关键帧图 + Remotion 混合流」。

### 4. 风格 F（手绘素描涂鸦手书）代码要点
- 核心灵魂是 **煮沸线滤镜**：`<feTurbulence baseFrequency="0.032" seed={Math.floor(frame / 3) + 1} />` + `<feDisplacementMap scale={3.6} />`，让全部手绘炭笔线条每 3 帧自然颤动；
- 阴影使用倾斜 SVG `<pattern>` 铅笔排线填充；
- 严格遵守「黑白素描 + 最多 2 种荧光高亮色（如炽红 `#EF233C` + 荧光黄 `#FDE047`）」，情绪张力极强。

### 5. 风格 G（白边贴纸手账绘本 / 旋律说唱卡点）代码要点
- **无黑描边平涂 + 白边模切贴纸外框（核心质感）**：人物与前景道具内部严禁画黑色线稿，全部用柔和扁平色块拼合；外部包裹独立 `<g filter="url(#...-sticker)">`（`x="-25%" y="-25%" width="150%" height="150%"`），通过 `feMorphology(dilate, radius=10)` + `feGaussianBlur(0.6)` + `feComponentTransfer linear(slope=16, intercept=-6)` + `feFlood(#FAF8F4)` + `feDropShadow` 生成统一模切白边与立体贴纸阴影。
- **紧凑 Q 版人物范式（`2.2–2.5` 头身）**：圆润方圆头，深咖发色配 **发顶 4 道短竖暖棕高光**（`#6E4530`），刘海高于眉毛至少 `6px` 以完整露出八字忧伤眉/弯眉；豆豆眼 + 柔焦粉椭圆腮红 + 白圆领拼色毛衣/卫衣。
- **双色域强反差 + 1.5–3s 一句一景说唱卡点**：按说唱 BPM 小节（如 90 BPM 下 4 拍 = `80f`）切换场景，在「深靛紫夜房 (`#1C2042`)」「亮冰白手账/手机屏幕 (`#E4EDF5`)」「50/50 深夜卧室×微信聊天分屏」「冷雨夜街×暖黄咖啡馆橱窗」间强反差切场；每句歌词具象化一个拟态 UI/数据道具（微信已读气泡、凌晨 `02:47` 闹钟、`12%` 电量、情绪刻度量杯、雾气玻璃简笔画）。
- **无黑栏 16:9 满铺 + 奶油纸卡字幕条 + 顶部微倾双星红标贴纸**：全屏叠固定 `seed` 织物纸纹；开场顶部居中 `-1.5°` 微倾奶油贴纸配**左右双亮黄五角星**与底部偏右**珊瑚红胶囊歌手标签**；底部 `y ≈ 905..995` 放暖奶油矩形纸卡（`#FAF6EE` + 暖米色底厚 + 深炭黑粗无衬线字），**绝不使用底部黑边栏**，且所有透明雨伞/柔焦光晕必须置于贴纸滤镜外层防止白块化。
- **风格 G 6 大说唱节奏转场库（严禁全片单一硬切）**：
  1. `zoomBurst` **穿屏推镜转场**：旧幕末段 10f 高速推镜放大至焦点（手机/照片），瞬间穿进新幕并带微过冲弹稳与轻白光环；
  2. `wavyWipeWhite` / `wavyWipePink` **手账波浪发光白边/粉边撕纸刮擦**：垂直正弦波浪轮廓从左向右扫开，切线边缘叠一条带发光外晕的 12px 亮白/亮粉贴纸切边；
  3. `rainCurtain` **重雨幕叠化降落**：切场瞬间 3× 粗密斜雨丝刷屏，新场景随轻微下移交叉叠化浮现；
  4. `whipPan` **横向速度线摇镜推拉**：旧幕高速向左滑出、新幕紧贴从右滑入，全屏叠 16 条半透明纯白横向速度线；
  5. `bokehFlash` **梦幻虚化大光斑闪切**：22 枚粉/冰蓝/暖白/浅紫大号柔焦圆斑瞬间爆发覆盖接缝，随后扩散消散露出新幕；
  6. **深靛蓝息屏淡出**：尾声全屏平滑叠入深靛蓝 `#171B3A`。
- **8 大幕内卡点微动画**：
  1. 双星+红胶囊歌手标标题贴纸；
  2. 全片温和 Ken Burns 运镜 + BPM 强鼓点微缩放呼吸感；
  3. 挂钟高速转针 / 量杯百分比实时跳降 + 杯底裂纹漏出小心心 + 顶部通知条；
  4. 微信绿气泡随鼓点逐条弹出（带 `已读`）+ 底部输入框打字机逐字敲字与闪烁光标；
  5. 雾气玻璃 `strokeDashoffset` 实时绘制波折连线 + 眼泪半空凝结旋转冰蓝雪花；
  6. 幕内动态人物动作（如侧身转背影撑伞、远景撑伞路人横向走动、路面雨滴涟漪）；
  7. 强鼓点贴纸印章重砸（`scale 2.4 → 1.0` + 5 帧确定性画面微震）；
  8. 飘浮 `>` 手账折纸角碎片 / 焦虑蓝冷汗滴 / 拍立得闪光出片 / 窗台萌物卡拍蹦跳。
