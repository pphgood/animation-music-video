# 动画音乐 MV 配套封面图生成规范（4:3 横版 + 3:4 竖版）

> **适用范围（可选流程）**：本规范对应 Skill **阶段七（可选）**，仅在用户明确提出生成 MV 配套封面需求时按需触发，**不是每次制作 MV 的固定必选环节**。

本规范将「视频成片视觉特征提取 → 双比例海报生图 → 中文字形与比例双维度验收 → 归档交付」封装为标准操作参考，确保需要生成封面时，封面的角色造型、核心意象、画风工艺与渲染成片保持高度一致。

---

## 一、标准作业流程（5 步闭环）

### 1. 筛选成片代表关键帧（最多 3 张）
从 `<歌名>-MV/<slug>-mv/out/stills/`（若未抽帧可先用 `audit_stills.mjs` 抽取）精选 **3 张**最具代表性的高分帧作为生图参考锚点（`image-generator` 参考图上限通常为 3 张），务必覆盖：
- **主角标准造型帧**：清楚展示男女主发型、发饰、五官比例与固定服装配色；
- **核心情绪/高光意象帧**：展示代表全片灵魂的场景光影（如白月光、雨夜街与暖光咖啡馆、糖果罐、石桥古堡等）；
- **画风纹理基准帧**：体现实测画风工艺（如风格 A 粗墨描边纸纹 / 风格 G 无黑描边平涂+白色模切贴纸外框+布纹质感）。

### 2. 双比例构图与提示词模板
并行生成 **4:3 横版**（适配 B站、YouTube、长视频封面）与 **3:4 竖版**（适配抖音、小红书、网易云音乐竖版海报）两张**满铺无边框**封面：

- **必须遵守的画面铁律**：
  1. **严守原片画风一致性**：参考并严格复刻参考图画风（例如风格 G 必须明确要求「2D 无黑描边扁平矢量手账绘本风、角色带粗白色模切贴纸外框与柔阴影、深靛蓝细腻织物纹理底图」，严禁跑偏成 3D 渲染或写实日漫）；
  2. **仅保留两行干净标题**：只排版 **大号 `<歌名>`** 与 **小号 `<歌手>`** 两行清晰中英文标题，置入干净留白夜空/纯色区域（横版常置左上或右上干净天空，竖版常置顶部三分之一居中）；
  3. **零杂讯禁令**：严格禁止出现歌词条、微信聊天框、对白气泡、视频播放器 UI、四周黑边/相框、水印及任何多余装饰文字。

- **字体选型建议**：
  - 抒情/古风/故事风（风格 A/C/D）：优先选用 **奶油白清晰宋体**；
  - 旋律说唱/手账贴纸风（风格 F/G）：可选用 **暖奶油白粗圆润无衬线体或手账奶油贴纸风大字**（配极轻投影，保证字形笔画工整清晰）。

### 3. 调用 `image-generator` 生图并复制到工程封面目录
逐张或按需发起 `invoke_subagent`（`TypeName: "image-generator"`，遇限流时可间隔错峰顺序调用），在 Prompt 中显式提供：
- 参考关键帧绝对路径（最多 3 张）；
- 精确比例指令（`aspect ratio 4:3` / `aspect ratio 3:4`）与满铺无框要求；
- 收到 `image-generator` 返回的生成图像路径后，由主 Agent 复制/归档到：
  - `<歌名>-MV/封面/<歌手> - <歌名> - 横版封面 4x3.png`
  - `<歌名>-MV/封面/<歌手> - <歌名> - 竖版封面 3x4.png`

### 4. 双维度强制验收（全部通过方可交付）
1. **视觉与字形审查（必须用 `read_file` 看原图）**：
   - [ ] 歌名与歌手汉字/英文拼写 100% 正确，无缺笔、连笔畸变或 AI 伪汉字；
   - [ ] 角色发型、发饰（如白茉莉发夹、双呆毛）、服装配色与参考帧高度一致；
   - [ ] 画面无歌词字幕条、聊天气泡、额外水印、多余小字或上下左右黑边/白边相框；
   - [ ] 主体构图饱满，标题区与人物面部互不遮挡。
2. **像素宽高比实测（Python Pillow 校验）**：
   - 运行校验脚本核实实际 `width × height` 与比例：横版须满足 `w / h ≈ 1.33`（如 `1200×896`、`1408×1056` 等），竖版须满足 `w / h ≈ 0.75`（如 `896×1200`、`1056×1408` 等）。
   - 若某张未保存至目标路径，先将 `image-generator` 返回文件复制到目标路径后再校验；若字形或构图不达标，立即微调提示词定向重生成并复检。

> **兜底机制**：若连续两次生图出现中文字形畸变，可让 `image-generator` 生成顶部预留干净留白的**无文字纯画面底图**，再用 Python Pillow / Remotion SVG 精准叠加本地系统高清中文字体标题。

### 5. 双位置归档与提示词留档
- 在 `<歌名>-MV/封面/` 下写入 `生成提示词.md`，记录所引用的参考关键帧路径、双版构图说明与实测分辨率；
- 将两张定稿封面同步复制一份至 `<歌名>-MV/` 根目录：
  - `<歌名>-MV/<歌手> - <歌名> - 横版封面 4x3.png`
  - `<歌名>-MV/<歌手> - <歌名> - 竖版封面 3x4.png`
